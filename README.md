# Most Populous Contries in the World

A simple HTML and CSS project featuring a semantic, styled table that lists the world's most populous countries.

## About the Project

The goal of this project is to practice structuring semantic HTML tables and applying internal styling using the `<style>` tag, without relying on external frameworks or stylesheets.

### Displayed Data

The table is organized into three main columns:
1. **Rank**: Displays the country's global ranking (e.g., 1st place, 2nd, place).
2. **Country**: Displays the national flag alonside the country's name.
3. **Population**: Shows the total numbe of inhabitants in millions.

## Tech Stack

- **HTML5:**
  - `<table>`: Main container for the data table.
  - `<thead>` & `<th>`: Table header and column titles.
  - `<tdoby>` & `<td>`: Table body and individual data cells.
  - `<tfoot>`: Table footer (used for totals, notes, or data sources).
- **CSS3 (internal):**
  - `<style>`: Embedded styling inside the HTML document for borders, spacing and alignment.
